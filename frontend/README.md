# Frontend - Página de Donaciones

Frontend de la plataforma de donaciones desarrollado con Next.js y TypeScript.

## Tecnologías utilizadas

* Next.js
* TypeScript
* CSS Modules

## Configuración

Crear un archivo `.env.local` en la carpeta frontend:

```env
NEXT_PUBLIC_API_URL=http://localhost:3000
```

## Instalación

Desde la carpeta raíz del proyecto:

```bash
npm install
```

## Ejecución

Iniciar únicamente el frontend:

```bash
npm run dev:front
```

La aplicación estará disponible en:

```txt
http://localhost:3001
```

## Funcionalidades

* Registro e inicio de sesión.
* Publicación de objetos para donar.
* Búsqueda y filtrado de publicaciones.
* Gestión de solicitudes.
* Panel de usuario.
* Herramientas de moderación y administración.
