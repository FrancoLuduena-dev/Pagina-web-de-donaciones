    Class SolicitudService

    Servicio encargado de aplicar las reglas de negocio del ciclo de vida de las solicitudes.

    Coordina validaciones sobre la publicación relacionada, las decisiones del creador, los cambios de estado de la solicitud y los eventos de dominio que se disparan cuando el proceso avanza.

    • aceptarSolicitud(
          solicitudId: string,
          usuarioId: string,

      Acepta una solicitud pendiente.

      Esta operación compromete la publicación con un usuario y, por eso, el servicio también reserva la publicación para evitar que siga estando disponible para otros interesados. La ejecución se realiza dentro de una transacción con bloqueo para evitar inconsistencias.

      Parameters

      • solicitudId: string

        Identificador de la solicitud a aceptar.

      • usuarioId: string

        Identificador del usuario que intenta aceptar la solicitud.

      Returns Promise<SolicitudResponseDto>

      Solicitud aceptada serializada para la respuesta.

      Cancela una solicitud según el estado actual de la misma.

      Si la solicitud estaba pendiente, se cancela de forma simple. Si ya había sido aceptada, se libera la reserva de la publicación para que vuelva a estar disponible para otros usuarios.

    crearSolicitud

    • crearSolicitud(
          dto: CrearSolicitudDto,
          solicitanteId: string,
      ): Promise<SolicitudResponseDto>

      Crea una nueva solicitud sobre una publicación.

      Antes de persistirla, el servicio valida que la publicación pueda recibir solicitudes, que el usuario no sea el creador y que no exista ya una solicitud activa para esa publicación.

      Parameters

      • dto: CrearSolicitudDto

        Datos de la solicitud enviada por el usuario.

      • solicitanteId: string

        Identificador del usuario que realiza la solicitud.

      Returns Promise<SolicitudResponseDto>

      Solicitud creada serializada para la respuesta.

      Throws

      ForbiddenException Si el usuario intenta solicitar su propia publicación.

      Throws

      ConflictException Si ya existe una solicitud activa para la publicación.
