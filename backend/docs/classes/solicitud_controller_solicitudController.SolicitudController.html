    Class SolicitudController

    Controlador que expone los endpoints para gestionar solicitudes sobre publicaciones.

    Recibe las peticiones HTTP, delega la lógica de negocio al servicio y deja en Swagger la semántica de cada operación para el frontend y la documentación académica.
