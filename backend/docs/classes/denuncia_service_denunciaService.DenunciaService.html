    Class DenunciaService

    Servicio encargado de orquestar el flujo de denuncias.

    Implementa las reglas de negocio del módulo: valida que una denuncia sea válida, evita reportes duplicados o injustificados, administra los estados de revisión y aplica las decisiones de moderación sobre publicaciones o usuarios cuando corresponde.

    • crearDenuncia(

          dto: CrearDenunciaDto,

      Crea una denuncia para una publicación existente.

      Aplica las reglas de negocio principales del módulo: no se permite denunciar una publicación propia, tampoco se admiten denuncias duplicadas del mismo usuario sobre la misma publicación y el nuevo registro queda en estado pendiente para su revisión.

      Parameters

      • denuncianteId: string

        Identificador del usuario que realiza la denuncia.

      • dto: CrearDenunciaDto

        Datos necesarios para crear la denuncia.

      Returns Promise<DenunciaResponseDto>

      Denuncia creada en formato de respuesta.

      Throws

      ConflictException Cuando el usuario ya denunció la misma publicación.
