    Class Solicitud

    Entidad que representa una solicitud de interés sobre una publicación.

    Su estado refleja el avance del proceso entre el solicitante y el creador, mientras que las transiciones están restringidas por reglas de negocio.

    validarCreadorPublicacion

    • validarCreadorPublicacion(usuarioId: string, mensaje?: string): void

      Valida que la acción sea ejecutada por el creador de la publicación.

      Esta regla protege decisiones sensibles del flujo, como aceptar, rechazar o finalizar una solicitud, porque solo el propietario de la publicación puede decidir cómo avanza el proceso.

      Parameters

      • usuarioId: string

        Identificador del usuario que intenta ejecutar la acción.

      • mensaje: string = 'Solo el creador de la publicación puede realizar esta acción'

        Mensaje alternativo para el caso de no tener permiso.

      Returns void

      Throws

      ForbiddenException Cuando el usuario no es el creador de la publicación.

    • validarPuedeCancelarsePor(usuarioId: string): void

      Valida si un usuario puede cancelar la solicitud según su estado.
